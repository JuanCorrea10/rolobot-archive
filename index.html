Six doors. Each one wants a key.

A key is a word, and it is always hiding somewhere: on the page, or out in the world.

Nothing here is random. Everything is on purpose. Even the mistakes.

how does this work?

Behind each door there is a box. Type the key into it. Capital letters, spaces and punctuation don't matter.

You don't need to know anything about computers. You need to be curious. Google, Wikipedia, YouTube and Spotify are all part of the game.

Stuck? Type hint into the box. There are two or three hints behind every door. Type joke if you just need a break.

Your progress is remembered in this browser only. Nothing is sent anywhere. There is no server. There is only you and the doors.

The first door has no key. It has no handle either. It is simply very, very hard to see.
